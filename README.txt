CAP — MON BIEN-ÊTRE

Application mobile PWA personnelle. Aucun service payant, aucun serveur de données, aucun compte.

Déjà configuré :
- Date de commencement : 11 octobre 2026
- Poids de départ : 107 kg
- Téléphone coupé après 22h
- Objectif de coucher initial : 23h (modifiable dans Réglages)
- Suivi bien-être /10, repas, boissons, habitudes, sommeil et poids

INSTALLATION (COMME AI ACADEMY)
1. Décompresse l'archive ZIP.
2. Crée un NOUVEAU dépôt GitHub public nommé, par exemple, « cap-bien-etre ».
3. Ajoute à la racine du dépôt tous les fichiers décompressés (pas le dossier parent).
4. GitHub > Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. L'adresse sera, si tu gardes ton compte GitHub habituel : https://jawadjbag.github.io/cap-bien-etre/
6. Sur iPhone, ouvre ce lien dans Safari > Partager > Sur l'écran d'accueil > Ajouter.

Les données restent sur l'appareil dans le stockage du navigateur. GitHub héberge UNIQUEMENT le code de l'application et non tes bilans.
Attention : la suppression des données Safari, une réinstallation ou un changement d'appareil peut effacer le journal. Dans l'app, Réglages > Exporter mon journal permet une sauvegarde JSON et Importer une sauvegarde permet la restauration.

Pour tester sans GitHub : ouvrir index.html dans un navigateur donne accès à la plupart des fonctions, mais l'installation PWA et le mode hors ligne nécessitent une adresse HTTPS (GitHub Pages).
